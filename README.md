# 调色推杆

一个无需安装依赖的 RGB 调色小游戏。观察题目颜色，拖动红、绿、蓝三根推杆，让自己的颜色尽量接近它。每局 5 轮，分数按人眼感知色差计算。

## 开始游戏

- **Windows**：双击 `启动游戏.bat`，它会通过 `launch.vbs` 在 Edge 或 Chrome 的独立窗口打开游戏。
- **其他系统**：直接用现代浏览器打开 `index.html`。

游戏完全在本地运行，不需要服务器或账户。

## 玩法

1. 在首页选择难度：休闲不限时并显示 RGB 数值；标准每轮 30 秒；挑战每轮 15 秒。
2. 对照左侧题目颜色，调整右侧颜色的三根推杆。
3. 锁定答案，查看本轮分数与色差；完成 5 轮后查看总成绩。

推杆支持鼠标、触摸、滚轮和键盘操作。最高成绩保存在当前浏览器的本地存储中；可在游戏内切换音效。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构及游戏界面 |
| `styles.css` | 响应式布局与视觉样式 |
| `game.js` | 回合、计时、交互、音效及成绩保存 |
| `color.js` | RGB 到 Lab 的转换与色差评分 |
| `启动游戏.bat`、`launch.vbs` | Windows 快速启动器 |

不需要构建步骤或第三方包。修改前端文件后，刷新浏览器即可看到变化。
